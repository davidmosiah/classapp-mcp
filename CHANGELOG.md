# Changelog

## 0.1.0 — unreleased candidate

- Local stdio tools for profiles, notice search, fixed message reads and private
  attachment downloads; synthetic offline mode is the default.
- Exact network allowlists, bounded responses, safe errors and no automatic retry.
- Private credentials/downloads reject Git ancestry, linked worktrees, symbolic
  links and unsafe ownership/permissions.
- Explicit distinction between disabled read-update requests and unproven backend
  side effects; historical observations do not certify current provider behavior.
- Community documentation, parent guide, threat model and release inspection.

No public release or broad multi-account compatibility is claimed.
